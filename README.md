# Fitness Multi-Agent Router

Planning repo for the fitness coaching multi-agent take-home.

## Documents

- [REFERENCE.md](./REFERENCE.md) captures the local OpenEMR/HealthlyBot intent-router precedent and what should or should not transfer.
- [ARCHITECTURE.md](./ARCHITECTURE.md) defines the preliminary LangGraph architecture for the assignment.

## Current Scope

This repo is intentionally documentation-first. The planned implementation is a LangGraph hub agent that uses LLM structured output to route requests to separate sub-agent graphs for coaching, workout generation, workout logging, or clarification.
